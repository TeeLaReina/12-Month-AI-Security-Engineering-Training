# AI Security Engineering - 12-Month Training

A self-directed, 12-month program calibrated to the standard of AI security engineers at frontier AI labs. It takes me from zero AI/ML background to applied AI red teaming and defence.

Two tracks run in parallel and converge in one end-to-end capstone:

- **Track A - AI Security:** six domains in sequence, covering ML fundamentals, attack surface, red teaming, application security, MLOps/infrastructure security, and governance.
- **Track B - Cloud Engineering:** AWS, Google Cloud, Azure and DigitalOcean, in service of hosting and securing the AI work.

This repo is the public record: code, notes, screenshots, broken-then-fixed write-ups, and open-source contributions for every month.

## Structure

Folders are created when a month starts, not scaffolded in advance. Each month folder holds:

- `README.md`: what the month covered, what was built, what broke, and what I learned
- `notes/`: write-ups and research summaries
- `screenshots/`: evidence of the work

Program-wide logs (decisions, failures, open-source contributions) are added as they're needed.

## Ground rules

- Infrastructure is built from scratch when needed and destroyed after, not left running.
- Every tool version is confirmed against official documentation at install time.
- No secrets, keys, tenant IDs or personal data in commits or screenshots.
